# Security Policy

## Supported Versions

The latest public release of this project receives security-related updates and fixes when applicable.

| Version           | Supported          |
| ----------------- | ------------------ |
| Latest Release    | :white_check_mark: |
| Previous Releases | :x:                |
| Archived Versions | :x:                |

## Reporting a Vulnerability

The security of users and contributors is taken seriously. If you discover a security vulnerability within this project, please report it responsibly and privately.

### How to Report

Please send a detailed report to:

**Email:** [joegatimu20@gmail.com](mailto:joegatimu20@gmail.com)

Include the following information where possible:

* Description of the vulnerability
* Steps to reproduce the issue
* Potential impact
* Suggested remediation (if known)
* Screenshots, logs, or proof-of-concept examples

### Response Timeline

* Initial acknowledgment: within **7 business days**
* Assessment and validation: as soon as reasonably practicable
* Remediation updates: provided where appropriate for confirmed vulnerabilities

### Responsible Disclosure

Please do **not** disclose security vulnerabilities publicly until they have been reviewed and addressed. Responsible disclosure helps protect users of this software.

### Scope

This policy applies to the source code, deployment configurations, and components maintained directly within this repository.

Issues resulting from misconfiguration of third-party services, hosting environments, user-managed infrastructure, or modifications made outside this repository may fall outside the scope of this policy.

## Security Best Practices

Users deploying this application are encouraged to:

* Use supported PHP versions.
* Keep server software and dependencies updated.
* Restrict access to administrative interfaces.
* Protect API credentials and sensitive configuration files.
* Deploy using HTTPS where applicable.
* Perform regular backups of application data.

Thank you for helping improve the security of this project.
